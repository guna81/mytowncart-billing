Install on your device

Windows 10 / 11
  1. Download the Windows installer above and run it.
  2. If SmartScreen says Windows protected your PC, click More info → Run anyway.
  3. Optional: check the download. In PowerShell run Get-FileHash .\MyTownCart-Billing-windows-x64.exe -Algorithm SHA256 and compare with checksums-windows-x64.txt on the release page.
  4. Open MyTownCart Billing from the Start menu and follow the setup wizard.

Upgrading: just run the newer installer; your data is kept. Use the MSI if your IT team deploys software.

macOS
  1. Pick the right file: → About This Mac. A chip named Apple M1/M2/M3… means Apple Silicon; Intel means Intel.
  2. Open the downloaded .dmg and drag the app to Applications.
  3. Because the app is not notarized, macOS may say it is damaged. In Terminal run:
xattr -cr "/Applications/MyTownCart Billing.app"

Then open it again (or right-click → Open). Verify with shasum -a 256 <file> against the checksum file for your Mac.

Linux

Debian / Ubuntu: sudo apt install ./MyTownCart-Billing-linux-x64.deb

Other distributions: chmod +x MyTownCart-Billing-linux-x64.AppImage && ./MyTownCart-Billing-linux-x64.AppImage (needs WebKitGTK 4.1).

Verify with sha256sum --check checksums-linux-x64.txt in the download folder.

Phone or tablet (Android / iPhone / iPad)

There is no phone or tablet app. A phone or tablet can use billing through a browser while the desktop app runs on a computer on the same shop Wi-Fi: on the computer open Settings → LAN server, start it, then open the shown address (or scan the QR code) on the phone and enter a PIN. See the LAN guide. This needs a build that includes the LAN server and a trusted network.

Get started in five steps

  1. Install the app from the download section above.
  2. Enter your shop name, GST settings, and invoice prefix.
  3. Add products with prices, barcodes and opening stock, or import a CSV.
  4. Scan or search products, record the payment, then save and print your first bill.
  5. Set up encrypted backups in Settings and keep your recovery key somewhere safe.

Guides: shop operator guide · screens & workflows · backups · marketplace sync

Handy shortcuts: F2 scan field · F4 hold bill · F9 save & print.

Your data stays on your computer

Bills and customer data live in a local SQLite database on the shop's PC. Linking a MyTownCart account sends catalog fields, stock changes and order pulls to the marketplace. Development builds can also share shop data with LAN browsers when the optional server is enabled, and contact GitHub to check for new releases. Backups are encrypted before they are written, and diagnostics are off by default.

FAQ

Is it really free and open source?

Yes, under the Apache License 2.0. The MyTownCart name and logo are covered by a trademark policy, so forks must use a different name.

Does it work offline?

Yes. Everyday billing uses local storage. Publishing and syncing with MyTownCart need internet and a linked account.

Does it support GST and receipt printers?

Yes: shop GST settings, item tax rates, CGST/SGST, A4 invoices, and 58 mm / 80 mm receipts via the system print dialog.

Does recording UPI or card process the payment?

No. The POS records the payment mode on the bill; complete the payment with your usual UPI or card service.

How do I get the new features?

Check the source and release notes. Download buttons point to the latest published installer and update on their own when a release is published; source changes need a new desktop build. Development release notifications open GitHub for manual download and installation.

Found a bug or want a feature?
