Windows install notes

SmartScreen will warn: click More info → Run anyway. Verify the installer against checksums-windows-x64.txt from the release with certutil -hashfile <file> SHA256.

macOS install notes

Drag the app to Applications, then if Gatekeeper says it is damaged, remove the quarantine attribute:

xattr -cr "/Applications/MyTownCart Billing.app"
Linux install notes

AppImage: chmod +x MyTownCart-Billing-v0.1.2-linux-x64.AppImage and run it. Debian/Ubuntu: sudo dpkg -i MyTownCart-Billing-v0.1.2-linux-x64.deb.

Get started in five steps

  1. Install the app from the download section above.
  2. Enter your shop name, GST settings, and invoice prefix.
  3. Add products with prices, barcodes and opening stock, or import a CSV.
  4. Scan or search products, record the payment, then save and print your first bill.
  5. Set up encrypted backups in Settings and keep your recovery key somewhere safe.

Guides: shop operator guide · screens & workflows · backups · marketplace sync

Handy shortcuts: F2 scan field · F4 hold bill · F9 save & print.

Your data stays on your computer

Bills and customer data live in a local SQLite database on the shop's PC. Linking a MyTownCart account sends catalog fields, stock changes and order pulls to the marketplace. Development builds can also share shop data with LAN browsers when the optional server is enabled, and contact GitHub to check for new releases. Backups are encrypted before they are written, and diagnostics are off by default.

FAQ

Is it really free and open source?

Yes, under the Apache License 2.0. The MyTownCart name and logo are covered by a trademark policy, so forks must use a different name.

Does it work offline?

Yes. Everyday billing uses local storage. Publishing and syncing with MyTownCart need internet and a linked account.

Does it support GST and receipt printers?

Yes: shop GST settings, item tax rates, CGST/SGST, A4 invoices, and 58 mm / 80 mm receipts via the system print dialog.

Does recording UPI or card process the payment?

No. The POS records the payment mode on the bill; complete the payment with your usual UPI or card service.

How do I get the new features?

Check the source and release notes. Download buttons point to the latest published installer; source changes need a new desktop build. Development release notifications open GitHub for manual download and installation.

Found a bug or want a feature?

Open an issue on the GitHub issue tracker.
